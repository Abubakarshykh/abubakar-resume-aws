## ◈ &nbsp;About

I'm **Muhammad Abubakar**, a computer science student and developer based in Islamabad, Pakistan. I work across frontend interfaces and backend services, with a focus on making applications feel **clear, responsive, and reliable**.

I enjoy taking an idea from the first rough sketch to a working product: building the UI, connecting APIs, shaping data, and sweating the details that make the whole experience better.

> *Developer by craft. Problem-solver by nature.*

This repository contains my personal portfolio: a fast, dependency-free, three-page static site designed with intention.

<br>

## ⌁ &nbsp;Highlights

| | |
|:--|:--|
| **Pure static stack** | Hand-written HTML, CSS and a tiny vanilla JS file. No frameworks, no build step. |
| **Considered design** | Dark editorial theme with a teal → violet gradient accent and ambient glow. |
| **Typography** | [Manrope](https://fonts.google.com/specimen/Manrope) for text, [DM Mono](https://fonts.google.com/specimen/DM+Mono) for labels and code. |
| **Fully responsive** | Fluid layouts with breakpoints at `850px` and `600px`, plus a mobile navigation menu. |
| **Accessible touches** | Semantic markup, ARIA-labelled controls, and `prefers-reduced-motion` support. |
| **Subtle motion** | Floating tech chips and hover transitions, disabled automatically for reduced-motion users. |

## ▸ &nbsp;Getting Started

No installation required. Clone the repository and open it in a browser.

```bash
# Clone
git clone https://github.com/Abubakarshykh/<your-repo-name>.git
cd <your-repo-name>

# Option 1: open directly
open index.html

# Option 2: serve locally
npx serve .
# or
python -m http.server 8000
```

Then visit `http://localhost:8000`.

<br>

## ✦ &nbsp;Deployment

Because the site is fully static, it deploys anywhere in seconds:

- **GitHub Pages**: Settings → Pages → deploy from the `main` branch
- **Vercel / Netlify**: import the repository, no build command needed
- **Any static host**: upload the five files
